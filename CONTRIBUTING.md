# Contributing

## How we collaborate
1. Create a branch from `main`.
2. Make focused changes.
3. Open a pull request with context and screenshots/logs if useful.
4. Get at least one review before merge.

## Commit guidance
- Use clear commit messages.
- Keep unrelated changes in separate commits.

## Security
- Never commit secrets (tokens, passwords, API keys).
- Use environment variables for local sensitive values.

## Scope reminder
This repository is intentionally initialized for team collaboration and planning.
Do not add starter application code until the team agrees on architecture.
